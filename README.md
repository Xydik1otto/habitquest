# habitquest

**Local-first gamified habit tracker** — звички як RPG: XP, рівні, серії з «заморозками» та досягнення. Усе локально, жодних підписок.

## Проблема

- Health & Wellness — найшвидше зростаюча категорія застосунків (сплеск у січні 2026, зі скану 9363 постів); habit/gym-трекери стабільно вгорі запитів.
- Subscription fatigue: більшість habit-трекерів — це підписка $4–6/міс за функції, які є звичайною CRUD-логікою над локальними даними.
- Ігрові елементи (стрики, XP) утримують краще за «сірі» списки, але топові гравці (Habitica, Streaks) — хмара або paywall.

## Рішення (MVP)

Python FastAPI + SQLite + vanilla JS. Нуль зовнішніх сервісів, нуль підписок,
дані експортуються/імпортуються одним JSON-файлом.

### Гейміфікація

- **XP за чек-ін** зі стрік-множителем (довша серія → більше XP).
- **Рівні** з порогами (кумулятивна формула).
- **Стрик-вогник** ❄/🔥: серія днів; 1 **freeze token** на тиждень «заморожує»
  пропущений день, не ламаючи серію.
- **Досягнення**: first week, 30 days, comeback (повернення після паузи).

### Вьюхи

1. **Day view** — сьогоднішні звички з чекбоксами (daily) і прогресом тижня (weekly).
2. **Week heatmap** — SVG-сітка «тижні × дні» з кількістю чек-інів.
3. **Stats** — найдовша серія, % виконання за 30 днів, рівень/XP гравця.

### Data portability

`GET /api/export` → JSON; `POST /api/import` → повне відновлення. Дані завжди ваші.

## Швидкий старт

```bash

python -m uvicorn app.main:app --reload
# http://127.0.0.1:8000

```
